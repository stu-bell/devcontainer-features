

# Dev Container Features

This repo is a collection of dev container features. Follow the links below for documentation on each feature:

- [Claude Code](./src/claude-code) - AI code assistant [code.claude.com](https://code.claude.com)
- [Cursor CLI](./src/cursor-cli) - AI code assistant [cursor.com/cli](https://cursor.com/cli)
- [Gemini CLI](./src/gemini-cli) - AI code assistant [geminicli.com](https://geminicli.com)
- [Neovim](./src/neovim) - Neovim editor, with config via Git [neovim.io](https://neovim.io)
- [Node.js](./src/node) - this is a dependency feature only
- [Open Code](./src/open-code) - AI code assistant [opencode.ai](https://opencode.ai/)
- [ttyd](./src/ttyd) - Share your terminal over the web [tsl0922.github.io/ttyd](https://tsl0922.github.io/ttyd)
